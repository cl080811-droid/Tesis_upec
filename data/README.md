# Datos

## Estructura esperada
- raw/images/: imágenes originales.
- raw/videos/: videos de cámaras fijas.
- processed/images/: imágenes preparadas.
- processed/labels/: etiquetas YOLO.
- annotations/: archivos de anotación.
- splits/: división train/val/test.
- cattle.yaml: configuración del dataset YOLO.

No subir datasets pesados ni material con restricciones de uso al repositorio. Registrar en la documentación el origen y licencia de cada conjunto de datos.
